# 重资产的叙事角色分层:记忆入第二幕、协作打组织牌、harness 走内容轨道

三块工程含量最高的资产(记忆宫殿/官员协作/harness-loop)在首屏叙事收窄后曾被统称"护堤"。本决策为它们各定角色而不稀释首屏:

1. **记忆宫殿升入第二幕**:「越用越懂你」重定义为双引擎——记忆是快变量(day-2 即可感)先演,进化是慢变量(请旨解锁后)接棒,一句话:**记忆感知,进化固化**。此举同时填补 ADR-0004(进化默认关)造成的第一周体验空窗,并细化 ADR-0002 的"自进化第二幕"表述。
2. **官员协作不打"multi-agent 协作"牌**(CrewAI 主场红海,且与"六部=同一模型不同权限约束"的诚实分层有张力),打**「组织新陈代谢」**无人区牌:官员是有生命周期的组织成员——被考核(京察)、被进化(位面变异)、被淘汰(致仕)、准入要考试(科举);会诊/DAG/委派作为"敢放手"的技术背书出现,不独立成卖点。
3. **harness/loop 不进卖点,走技术内容轨道**:它解决的不是用户痛点而是工程师信任;每迭代随 minor 版本发一篇深度技术文(候选队列:三层 compaction、L0–L3 外环、位面配对评估、记忆宫殿分层、泳道与级联取消),带宽从既有的 25% 社区预留出——首发热度之后,开源影响力靠内容节奏续命,HN 第二波弹药亦从中来。
