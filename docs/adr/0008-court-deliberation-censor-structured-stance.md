# 廷议定位为治理原语「大事慎决」,以言官制度强制分歧,废除 confidence 换结构化立场

背景:consultation 此前只在长任务 L2 升级时触发(唯一消费者 `orchestrator/loop.py`),同质化征询(六官员同构 prompt、同一底模)导致意见趋同、信息增量趋零;`PersonaOpinion.confidence` 为硬编码占位值;"会诊/会商/廷议"三词并存。三项决定:

1. **定名「廷议」(Court Deliberation)并升为治理原语**,与司礼监代批成对——小事快批 × 大事慎议,补齐"敢放手"叙事的另一半。三个接入面:L2 升级(已有)、高风险批红一键召廷议(迭代 5,人机在环主题)、位面晋升廷议门(迭代 6,晋升审批附多视角白话论证而非只有 fitness 数字)。"会诊"让给太医诊断器,避免隐喻撞域。
2. **双结构强制分歧**:官员征询 prompt 按部门职能定制审视维度(户部算成本/都察院看风险合规/兵部评可行性/文渊阁从记忆宫殿检索历史先例),且每场廷议指定至少一名**言官**强制唱反调(职责=找出议案最大漏洞,即使内心赞成)。单模型多角色在无强制立场时天然趋同,结构性对抗是廷议有信息增量的前提;成本与现状同量级(N+1 次调用)。
3. **废除 confidence 字段**:LLM 自报置信度是伪精度(0.8 与 0.6 无可靠区分度),修得再真也是玄学。换成 `stance`(赞成/反对/有条件赞成)+ 条件清单 + 论据,纪要按立场分栏,留痕进审计——删伪精度,换人在批红时真正可用的决策输入。
