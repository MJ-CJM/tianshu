# 自进化默认关;行为层达阈值后「请旨解锁」,代码层永远手动

未来读者会问:最稀缺的功能(位面自进化)为什么出厂默认关?因为新用户信任建立期不应有后台变异行为与沙箱评估成本(与"先建立信任再放手"的时序矛盾,且首周账单意外是口碑杀手)。解法不是文档引导手动开(钩子哑火),而是**把功能开关做成剧情事件**:系统积累到阈值(如 20 个审计通过的 memorial 或运行 7 天)后,主动上一道「臣请开启自我演化」奏折——附将做什么/花多少钱/如何回滚——用户批红后开启行为层演化。这与"连自我进化都要请旨"的治理叙事自洽,且留存钩子更强(手机收到"你的衙门请求进化")。**代码层演化(自改代码)风险级别更高,不设自动请旨,永远由用户显式开启。**
