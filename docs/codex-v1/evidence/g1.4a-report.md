## Honest limits

- A detached Git worktree protects the source repository from cooperating
  staging mutations; it is not a strong sandbox and cannot prevent same-UID
  absolute-path writes or external-system side effects.
- Direct symlink replay and repository/worktree identity replacement are checked,
  but path checks alone do not eliminate same-UID TOCTOU. Runtime lease binding
  and any dirfd or verified strong-sandbox boundary remain G1.4b work.
- Tests assert source worktree content/modes, HEAD, refs, index, and status remain
  unchanged. They intentionally do not claim the source `.git` administrative
  metadata is byte-identical because Git legitimately creates/removes temporary
  worktree administration entries.
- No governed apply is enabled by this slice. Decision/receipt tables only freeze
  the identity, hash, expiry, token-hash, single-consumption, and rollback-evidence
  fields required by G1.4b.
- Crash-point exactly-once recovery remains G2 scope; platform claims remain
  Linux/macOS only.

## Post-review identity hardening (2026-07-12)

- Persisted immutable source and per-worktree Git administration identities.
  Durable `STARTING` remains first; `workspace_staging_identities` is recorded
  only after exact detached-worktree inspection and before `ACTIVE`.
- Persisted and validated the source symbolic ref, so switching branches at the
  same commit now fails replay, capture, close, and apply-decision binding closed.
- Cleanup now uses the lexical staging destination, rejects symlink replacement,
  and supplies the exact registered worktree authority even when the worktree
  directory is already missing. A pre-authority creation failure remains readable
  as `cleanup_failed` and cannot delete an unowned replacement path.
- Canonical inspect/capture now use a private temporary index and object database
  with source objects as read-only alternates. Unique uncommitted blobs are not
  discoverable from the source repository before or after capture/close.
- Added exact root/retry lineage validation in model, service, and SQLite; added
  cross-record source/base/ref triggers; tightened canonical change shapes; and
  return state versions from the same locked write transaction that inserted them.
- Same-run replay is now admitted into lifecycle shutdown tracking and re-reads
  exact lease/staging identity after blocking operations before it can return.
