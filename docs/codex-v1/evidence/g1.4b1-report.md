# G1.4b1 Runtime workspace binding implementation report

## Scope delivered

- Added task-local `BoundWorkspace` binding with nested/error/cancellation/task
  isolation, staging-directory identity freezing, active lease/contract/root
  validation, one shared async tool lock, and explicit child-run authorization.
- Removed fabricated `legacy:{run_id}` lease identities. Governed prepared
  executions require a matching real lease; legacy execution remains compatible
  with `workspace_lease_id=None`.
- Bound `ExecutionRequest` and governed shell, grep, LSP, lark-cli, and Keqing
  command grants to the real lease, staging root, cwd, and environment. Gateway
  admission revalidates the current ContextVars and rejects replay/root drift.
- Resolved active roots per invocation for builtins, edit/list/find/grep,
  lark-cli, LSP, Keqing, and `PolicyHook`; bootstrap-time source roots are no
  longer used during a bound run.
- Serialized every tool tier, including T0, through the lease lock. Governed
  calls without the matching lease fail closed, and actual MCP tool names are
  rejected while MCP remains a long-lived source-root process.
- Confined `skill_manage` mutations to staging `/skills`. Existing source/user/
  builtin skills are copied into the overlay before edit/resource mutation, so
  source skill bytes are not changed; `skill_list` and `skill_view` resolve the
  same overlay so new or edited skills are immediately visible to the run.

## Deferred by slice boundary

- Lease creation, restore-point creation, terminal capture/cleanup, retries, and
  Executor lifecycle wiring are G1.4b2.
- DAG root/worker lease inheritance and child authorization calls are G1.4b2;
  b1 provides only the explicit `authorize_run` primitive and defaults to the
  lease root run.
- Governed apply service, REST/CLI, auth scope, and capability promotion remain
  later G1.4b slices.
- Acceptance grants are not yet lease-bound in b1. Their requests still require
  the correct active staging root; grant binding moves with acceptance lifecycle
  wiring rather than prematurely breaking the existing caller.

## Honest limits

- ContextVar routing and Git worktrees are cooperative isolation, not a strong
  same-UID filesystem sandbox. Absolute-path writes outside the tool boundary
  remain a declared residual risk.
- Root inode/device and symlink replacement are checked at binding and use, but
  path validation does not eliminate every host-level TOCTOU race.
- MCP is deliberately unavailable inside an isolated run until it has a genuine
  per-run process/root boundary; this slice makes no false lease-bound claim.
