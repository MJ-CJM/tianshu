## 交互验收记录

1. `中枢总览 → 查看并裁决`：页面切换正常。
2. 空理由点击“批准执行”：显示“请填写裁决理由”，不产生裁决。
3. 填入理由后批准：理由首尾空白被去除，结果锁定，输入和三个动作禁用。
4. 返回中枢再打开敕令：裁决结果、依据与锁定状态保持。
5. 点击“恢复初始状态”：理由、结果清空，输入和三个动作恢复可用。
6. 点击“驳回”：只报告本地验收状态更新，不声称写入真实治理时间线。
7. `位面 → 演化中心`：页面切换正常。
8. Canary `18 / 50`：批准晋升保持禁用，原因与达到 50 后才开放的规则均可见。
9. 点击“继续观察”：明确尚未写入真实演化档案。
10. 选择 `Canary` 筛选：只显示 Canary 样本卡，页签选中态正确。
