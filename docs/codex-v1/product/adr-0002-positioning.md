# 定位「Claude Code 的上级机关」,首屏卖「敢放手」,自进化退居第二幕

目标人群(重度 AI 个人用户)手里已有每周用 20 小时的 Claude Code,与它正面竞争无胜算也不必要——天枢定位为其上层机构:异步多任务、批红审计、越用越懂你;以 MCP server(被它驱动)+ 客卿(反向驱动它)构成双向桥。三支柱中自进化的**市场稀缺度**最高,但按这个人群的**当下痛感**排序,"敢放手"(治理=信任基础设施,解"天天守着按 approve")才是首屏卖点——**卖点排序 ≠ 稀缺度排序**是本决策的核心洞察,自进化留作第二幕留存钩子。

## Considered Options

- "本地私有的 Manus"叙事——回避了与用户手中工具的关系(那把刀不会因此放下),弃;
- 自进化首发主打——信任门槛高、5 分钟 demo 演不出(需数据积累),弃。
