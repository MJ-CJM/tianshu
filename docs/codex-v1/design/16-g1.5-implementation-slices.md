Use with [G1.5 brief](./15-g1.5-wheel-demo-doctor-brief.md). Start only after G1.4 migration
numbers and workspace contracts are final.

## Slice A — exact wheel resources, overlay, and six defaults

- Add `tianshu.resources` catalog/overlay/default-persona helpers and package
  personas, 395 persona templates plus `SOURCES.md`, two builtin skills, Web
  static assets, executor templates, metadata/license, and `py.typed`.
- Preserve `web/public/brand.png` byte-for-byte; expected SHA-256 is
  `3f2bb6cfdcac70092fce3a9b8b534c4a0627f444cb9db38a9651087688ace799`.
- Read precedence is overlay over packaged defaults. All runtime writes/deletes
  target explicit HOME/data overlay; never write/delete under site-packages.
- Migrate bootstrap/persona/memory/skills/Web/template consumers away from
  repo-root inference. Keep workspace/eval roots explicit and separate from
  packaged resources.
- Append migration `MIGRATIONS[-1].version + 1`: seed exactly the six built-in
  departments only when `personas` is empty. Never overwrite, duplicate, or
  resurrect user-deleted rows outside the migration transaction.
- Fix `PersonaLoader.delete()` and `COURT.md` mutation so they never alter
  packaged defaults. Move writable plugins to overlay.
- Build/inspect the wheel; test repo-external cwd, read-only package, fresh HOME
  with spaces/non-ASCII, unchanged package digest, brand hash, overlay
  precedence, migration upgrade, non-empty DB, and deletion behavior.

## Slice B — explicit offline demo, Doctor, and readiness

- Add exact opt-in `startup_profile=demo` and `mock/tianshu-demo` at the common
  LLM dispatch boundary. Deterministic chat/stream/planner/audit/tool-shaped
  responses, cancellation, `[DEMO]` evidence, fixed zero-cost usage, and no
  network. Live-provider errors never fall back to demo.
- Add versioned `DoctorReport` with table/JSON rendering and stable check ids,
  required status, safe evidence, and remediation. Default is read-only. Do not
  expose key prefixes, secret paths, headers, queries, or raw values.
- Split `/health/live` and `/health/ready`; readiness fails for required DB /
  migrations, scheduler, worker, package resources, provider/profile, and
  WorkspaceService. Optional integrations are degraded only. Anonymous
  secure-remote readiness returns only schema/status.
- Add stable scheduler/worker readiness properties and update local startup and
  Web health consumers.
- Negative tests forbid LiteLLM/socket use in demo and exercise every required
  readiness failure independently.

## Slice C — exact-wheel fresh-HOME black box

- Build once and install that exact wheel into a repo-external venv/HOME path
  containing spaces/non-ASCII with cleared PYTHONPATH and user-site disabled.
- Tests may launch processes; do not add a new runtime/script process boundary.
- After dependency install, a test-only socket guard permits loopback/AF_UNIX
  only. Run Doctor, API/Web, live/ready, logo, six departments, builtin skills,
  and one governed isolated demo Edict through the final G1.4 interface.
- Assert `[DEMO]`, zero cost, lease/restore/change evidence, source invariants,
  no external network, clean SIGTERM, no ResourceWarning, DB quick-check, and
  unchanged package digest.

## Evidence boundary

- Local evidence is Darwin arm64 / current Python only. Do not claim Linux,
  Python 3.12, Windows, container runtime, public registry, OIDC, or publishing
  without external evidence. Container work belongs to G1.6.
