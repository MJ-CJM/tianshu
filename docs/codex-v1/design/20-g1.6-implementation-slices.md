# G1.6 implementation slices

Use with [G1.6 brief](./19-g1.6-security-release-brief.md). Implement system audit before MCP
admission because a security decision must fail closed if its audit cannot be
written. Let `N` be G1.5's final migration version; never guess numbers early.

## Slice A — append-only system audit and admin read surface (`N+1`)

- Add immutable `SystemAuditEventV1` and repository with sequence, safe actor /
  subject digests, correlation, action/outcome/reason, allowlisted metadata,
  previous hash and event hash. UPDATE/DELETE triggers reject forever.
- Verify the chain during pagination/export. Security state changes and their
  audit append share one Storage lock/transaction; audit failure rolls the
  security decision back.
- Cover token issue/rotate/revoke/session denial, estop transitions, and later
  MCP config/admit/deny/spawn terminal events.
- Reuse `admin` scope for `GET /api/audit/system` and export. Anonymous/API-only
  callers fail; output never contains credentials or unsafe endpoint data.
- G1 retains records indefinitely and exports verifiable chains; do not invent
  a delete-based retention policy that contradicts append-only truth.

## Slice B — MCP ciphertext and exact admission (`N+2`)

- Replace plaintext `mcp_server_overrides.env_json/headers_json` with encrypted
  canonical mappings and non-secret key metadata. Migration uses only the
  low-level vault and validates the master key before source mutation.
- Missing key/corrupt ciphertext fails explicitly with no plaintext fallback.
  Rotation includes MCP ciphertext. Successful active DB and later backups have
  no sentinel plaintext.
- Honest backup exception: a failed migration must preserve the original DB and
  raw pre-migration recovery backup, so those may contain legacy plaintext;
  mark them `legacy-sensitive`, mode 0600, never expose contents, and exclude
  from release images. Encrypting every historical backup is separate scope.
- Remote MCP: HTTPS only; reject userinfo/query/fragment and unsafe IP/DNS
  classes/mixed answers; disable redirects and proxy inheritance. DNS is only a
  preflight. Secure-remote denies remote MCP until a real trusted-egress
  boundary exists—no boolean escape hatch.
- New stdio servers default disabled and require an explicit non-empty approved
  tool set. Persist short-lived grants bound to complete principal, reason,
  expiry, executable realpath/digest/stat, argv/config hashes, lease/root,
  env-key/reference names, network/sandbox contract, and tool set. Any drift
  invalidates. Spawn remains through ExecutionGateway; discovered tools are
  intersected with approved tools.
- MCP writes/admin/admission routes require admin. Persist safe audit only.

## Slice C — exact-wheel container, CI, SBOM, threat/release evidence

- Consume the exact G1.5 wheel/hash/manifest. Multi-stage frontend/frozen
  wheelhouse/minimal runtime; fixed non-root UID/GID, explicit data/workspace
  volumes, readiness healthcheck, and no Node/compiler/cache/source tree in the
  runtime image.
- Add static Docker/workflow/release contract tests, Python+Web SBOM generation,
  release manifest verification, security scans, and a Developer Preview
  dry-run. Frozen dependencies, least workflow permissions, pinned verified
  action SHAs, no PR secrets, concurrency and finite retention.
- Add a threat model covering auth/TLS proxy, MCP, executors/sandbox, workspace
  apply, Web/WS, evolution, secrets/backups, audit, supply chain, and single-node
  limits. Sync public docs/capability truth.
- Runtime smoke with read-only rootfs, network-disabled demo, restart and clean
  shutdown only passes when a real Docker daemon exists.

## Evidence boundary

- Local environment cannot prove Linux, Python 3.12, Node 20, Docker runtime,
  scanners unavailable locally, multiarch, GitHub run identity, OIDC/signing,
  protected environments, GHCR/PyPI publication, production TLS/DNS, or trusted
  egress. Record these as `unverified` / `external_pending`, never fabricated.
