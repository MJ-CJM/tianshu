## 历史假设速览（非当前能力事实）

当时形成的核心假设是：把“治理、证据、成长”组合成长期差异化方向，并以开源先验证真实使用价值。它仍是产品研究输入，但其中的唯一性、生产安全性和完整闭环都尚未由 v0.4.x 证明，不能作为当前宣传语。

当前对外定位保持为“天枢是一个可治理、可验证、持续成长的自进化 Agent OS”，同时明确这是一条长期方向；只有通过相应 Gate 并在能力事实矩阵补齐证据，才能把具体能力升格为公开承诺。
