## 一页速览

**核心竞争力**:天枢是市场上唯一把「自进化」放进完整治理框架的 agent 平台——自进化敢上生产,因为每一步都被评估、审计、可回滚。三支柱:双层自进化闭环(独此一家)、治理组合拳(组合稀缺)、长任务 L0–L3 分级自治(无产品化对标)。

**主轴**:开源建影响力;加深不稀释;两段式发布(soft launch → 正式宣发);细粒度特性流(告别大 phase 分支)。

**排期主线**(单人+AI 高吞吐):

```text
迭代 0 地基(7/07–7/14)→ v0.2.0 soft launch
迭代 1 接入:MCP server 化 + LLM 可靠性(7/14–7/28)
迭代 2 证明:Evals v1 + 失败归因(7/28–8/18)
迭代 3 深防御:锦衣卫·运行时监察 + OTel(8/18–9/01)
迭代 3.5 客卿:反向驱动 Claude Code/Codex(9/01–9/10)
🚀 正式宣发(9 月中)→ v0.3.0
迭代 4 记忆 2.0 + 起居注(9/22–10/20)
迭代 5 执行与人机在环 2.0(10/20–11/10)
迭代 6 演化 2.0 + 画像驱动进化(11/10–12/05)→ v0.4.0
迭代 7 制度补全:司礼监/六科/实录馆/巡按/京察(12/05–12/22)→ v0.4.x 年终版
2027H1 P3:Runtime/Worker 解耦 → Actor → WS 房间;PG 可选
```

**明确不做**:computer use 自研、A2A(2026)、AG-UI、自研 LLM 重试框架、OpenFeature SDK、E2B、microVM、Temporal 默认、立即 PG/K8s、swarm 多 agent。
