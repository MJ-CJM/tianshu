# UI 视觉重塑「朱批」定案(2026-07-09)

> 用户诉求:浅色/深色都要「低调,但有设计感,不能让人感觉很平常」。
> 方案经三方向比稿(A 朱批 / B 黛青 / C 玄墨),用户拍板 **A 为主,细节保留调整余地**。

## 一、诊断

原状是一套接近 Vercel Geist 的近单色系统(暖白纸底 + 墨主色 + 宋体标题),方向正确但没有任何
属于天枢的记忆点;且存在四处与单色体系打架的硬伤:

1. 状态色是 AntD v4 糖果色实色块(`#1890ff / #52c41a / #ff4d4f / #722ed1…`),不分深浅模式;
2. GlowCard 运行光晕硬编码旧版蓝 `#1890ff`;
3. favicon 是青蓝科幻星芒渐变,与水墨纸感互相否定;
4. CostTrendChart 等处硬编码浅色边框,深色模式穿帮;页头标语用中文伪斜体。

## 二、设计宪法(方向 A「朱批」)

**墨为骨,朱为睛,纸为气。** 界面 98% 由墨/纸/灰阶构成;朱砂是唯一的品牌强调色,
只出现在「与主上朱笔有关」的地方:

- **待朱批 = 全屏唯一实色标签**(朱砂底反白字),一眼看到哪里等你落笔;
- 侧栏选中项左侧 2px **朱杠**(奏折眉批)+ 待批计数朱砂小盘;
- 页头**朱砂方印「枢」**,favicon 重上墨(墨环 + 朱砂枢轴,内嵌 `prefers-color-scheme`);
- Tabs 选中页签墨线用朱砂;`::selection` 朱砂淡染;`:focus-visible` 朱砂环(仅键盘);
- GlowCard 运行光晕改为朱砂极淡呼吸(尊重 `prefers-reduced-motion`);
- **朱砂不做普通按钮色**——主按钮保持墨(浅)/米白(深),克制才有分量。

## 三、色板(单一色源 `web/src/theme/palette.ts`)

| 角色 | 浅色「宣纸」 | 深色「烟墨」 |
|---|---|---|
| 页底 | `#F7F5F1` | `#161513` |
| 容器 | `#FFFFFF` | `#1E1C19` |
| 文字 | `#1F1E1B` | `#EAE6DC` |
| 次要字 | `#757167` | `#A29C8F` |
| 边线 | `#E5E1D8` | `#33302A` |
| 朱砂(强调) | `#AE3F2C` | `#D96C52` |

九态状态色一律低饱和「器物色」,浅/深各一套(竹月/苔青/殷红/赭黄/藕合/黛青/灰),
经 CSS 变量 `--ts-status-*` 随主题切换;`needs_review` 即朱砂。
深色不是浅色反相:底色偏暖,朱砂提亮两档,实色 chip 深色下改用墨字。
全部色值核对 WCAG AA(≥4.5:1)。

## 四、落地机制

- `theme/palette.ts` **唯一颜色事实来源**;`theme/index.ts`(AntD token)与
  `hooks/useTheme.ts`(CSS 变量注入)都从这里取值,组件禁止硬编码色值。
- **AntD 预设种子重调**:覆盖 `blue/green/red/…` 调色板种子,全部 `<Tag color="blue">`
  预设用法(82 处)一次性低饱和化,深色由 darkAlgorithm 自动推导;
  `colorInfo/Success/Warning/Error` + 状态 `Bg/Border` token 用与 SemanticTag 同配方
  (11%/30% 混入容器底)对齐,Alert/message/Result 随之统一。
- 新组件 `SemanticTag`:淡染底 + 细描边 + 本色字,`solid` 只允许「待朱批」使用。
- 自定义 hex 消费点全部转 CSS 变量;React Flow(DAG)的 marker/MiniMap 走 SVG 属性
  不支持 `var()`,按主题从 palette 取字面值。
- 排印:全局 `tabular-nums`;标语去伪斜体改衬线+字距;标题字距 0.04em;
  侧栏分组标题宋体小字(卷宗签条)。

## 五、验证

- 前端四件套全绿(eslint 0 error / tsc / vitest 17 passed / build);
- 无头 Chrome 实拍浅/深 × 御书房/敕令详情/都察院/户部账房八张核对;
- 实拍修正两处:深色主按钮文字色显式给墨字(`Button.primaryColor`,AntD 不自动翻转)、
  朱杠因菜单项 `overflow:hidden` 被裁改为项内 `left:0`。

## 六、保留的调整旋钮(用户验收时可点名调整)

1. 待朱批实色 chip → 可退为淡染;
2. 侧栏朱杠粗细/有无;
3. 运行光晕呼吸幅度/关闭;
4. 朱砂明度(浅 `#AE3F2C` / 深 `#D96C52` 可 ±);
5. 状态色九色的个别色相;
6. 可选加味(默认未做):浅色纸面噪点纹理、Empty 闲章。

## 七、不动项

页面结构、路由、业务逻辑、i18n 三套措辞(zh-classic 彩蛋原样)、测试语义。
