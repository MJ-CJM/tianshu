## 一句话定位

## 卖点排序(≠ 稀缺度排序)

1. **敢放手**(首屏)——治理=信任基础设施,直击"天天守着按 approve"痛点;
2. **越用越懂你**(第二幕)——记忆+自进化,一周后系统上「臣请自我优化」奏折;
3. **双向互操作**——Claude Code 下旨天枢 + 天枢派 Claude Code 出工。
