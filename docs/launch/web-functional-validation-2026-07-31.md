### 一次已披露的外部调用

切换到隔离环境前，对旧版太乙报告读取接口做 GET 探测时，发现该 GET 会隐式生成报告，
并实际触发了一次 DeepSeek 请求：耗时约 23 秒、总计 1,073 tokens、LiteLLM 原始
`cost` 字段为 `0.00084303`。发现后立即停止真实环境探测并告知用户。接口现已拆分为：

- `GET /api/universes/taiyi/report`：只读，绝不生成；
- `POST /api/universes/taiyi/report`：用户明确点击“生成奏折”才生成；
- eval 模式下 POST 返回可解释的 409，不接触外部模型。

修复后已在隔离浏览器中确认：进入页面只显示“尚未生成”，没有模型调用；点击生成按钮
得到 eval 边界提示，服务日志中没有外部模型请求。

## 本轮网页现场发现并修复的问题

1. **定时“即刻施行”误报租约过期**
   - 根因：调度生成的新奏折缺少 `run_evolution_assignments`，执行器在规划前的运行绑定
     阶段就退出；通用前置失败又没有立即落终态，30 秒后才被误报为
     `execution lease expired`。
   - 修复：自动触发、手动触发和幂等回放都在同一事务内写入当前运行分配；规划前失败
     也会立即形成最小失败投影并 fenced 收口。
   - 复验：同一个每日任务再次点击“即刻施行一次”，先显示“施行中”，随后显示“已成”；
     历史保留一条旧失败和一条新成功，日志显示 Planner 真正运行。

2. **租约失败没有投影到用户终态**
   - 修复 dead-letter 到奏折、运行状态、事件和调度历史的原子失败投影，避免“实际已死、
     页面仍候行”。

3. **太乙 GET 隐式耗模**
   - 改成只读 GET + 显式 POST；eval 模式 fail closed。详见上方外部调用披露。

4. **全局会话规则审计丢失**
   - 旧实现把空敕令 ID 写入任务事件表并吞掉外键异常；现改为追加式
     `system_audit_events`，创建和撤销都可追溯。

5. **事件总线审计页名称解析失败**
   - callable 没有函数名时使用稳定类名回退，页面不再因消费者对象而报错。

6. **DAG 重办稳定 422**
   - 前端补发幂等键并新增契约测试。

7. **长程任务完成后仍显示暂停按钮**
   - 暂停操作只在存在活跃奏折时出现，避免点击后固定 409。

8. **系统配置页错误态与请求风暴**
   - 为 Estop、MCP、Provider、Prompt、Skills、全局配置、任务槽、通政司、成本等补齐
     持久错误态；外部凭证移除不稳定依赖造成的重复 reload / 通知风暴。

9. **预算保存悄悄改成月度**
   - 保存金额时保留已有 `period` 与 `scope`；网页已验证 `daily` 不漂移。

10. **空状态与导航不完整**
    - 成长档案增加“立即合成”；定时和审计入口可达；会诊历史 / 错误可见；详情返回
      御书房；实验页明确成熟度和不可用边界。

11. **内存维护日期参数错误**
    - 压缩接口使用标准日期时间格式，网页维护操作可用。

12. **定时页键盘测试时序不稳定**
    - 保留键盘 Enter 行为和“菜单项真实可见”断言，仅等待 Ant Design portal 动画收口；
      不修改生产交互，也不把断言降级为“只存在 DOM”。

13. **客卿馆版本状态不会持续同步**
    - 后端原本已在每次状态请求时读取本机 CLI package 版本，但页面只在首次进入时请求；
      现在进入页面强制刷新、停留期间每 15 秒同步，并在窗口重新聚焦时立即同步。
    - Pi 的“已安装版本”与“已验证基线”继续分离：不会替用户自动升级，也不会把未经
      契约验证的新版本静默认定为兼容。本机 Pi `0.83.0` 已通过 85 项客卿定向测试和
      强制离线、零模型调用的 RPC `get_state` / `get_session_stats` 握手，验证基线同步到
      `0.83.0`。

  再从发布索引移除；

  清洁发布快照应重建公开安全证据，而不是静默篡改保留证据；
- 既有历史仍有已披露的第三方 publishable key 门禁：公开原历史前必须先轮换 / 撤销并
  重写复扫，或选择不携带该历史的清洁快照。

因此 `.gitignore` 已覆盖未来本机产物，但它不是“清除已跟踪历史”的替代品。当前
`publication_status` 继续保持 `not_authorized`。
