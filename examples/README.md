# 示例

本目录当前只包含一个**验证场景**，不是面向新用户的入门示例：

- [`lean-governed-evolution/`](./lean-governed-evolution/) — Lean Preview 13 步
  治理演化黄金场景的 runner 说明，面向想按哈希链复现验证发布产物的读者，
  运行前需要导出 provenance 环境变量。

想快速体验产品，请从 [快速开始](../docs/usage/getting-started.md)
（[English](../docs/usage/getting-started.en.md)）入手；功能全景见
[功能图鉴](../docs/usage/feature-tour.md)。

面向日常使用的最小示例（CLI 下达一道敕令、API 创建定时任务等）计划在
后续版本补充。
